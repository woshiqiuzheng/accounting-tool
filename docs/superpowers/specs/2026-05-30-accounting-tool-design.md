## 1. 项目概述

一个轻量级个人桌面记账工具，支持记录日常收支与转账、按分类和日期查询账单、查看统计图表、设置月度预算并接收超支提醒。数据全部存储在本地 SQLite 文件中，无需网络连接。

### 1.1 核心功能

| 功能 | 描述 |
|------|------|
| 记账 | 添加支出、收入、转账三种类型的账单 |
| 账单管理 | 查看、筛选、搜索、编辑、删除账单记录 |
| 月度统计 | 月度收支汇总表 + 分类占比饼图 |
| 预算管理 | 按分类设置月度预算，进度可视化 + 超支提醒 |
| 数据导出 | 导出账单为 CSV 文件 |
| 个性化设置 | 管理分类（自定义/重置）、管理账户、调整余额 |

### 1.2 不做（YAGNI）

- 多用户/登录系统
- 云同步
- 自动记账（OCR/银行导入）
- 多币种支持
- 系统通知/定时提醒
- 数据加密

## 2. 技术架构

### 2.1 依赖

```bash
pip install customtkinter Pillow matplotlib
```

所有依赖均轻量且可在 PyPI 直接安装，无额外系统级依赖。

### 2.2 项目结构

```
personal_accounting/
├── main.py                    # 应用入口
├── database/
│   ├── __init__.py
│   ├── connection.py          # SQLite 连接管理（单例）
│   ├── schema.py              # 建表 DDL
│   └── seed.py                # 预置分类/账户数据
├── models/
│   ├── __init__.py
│   ├── transaction.py         # 账单 CRUD
│   ├── category.py            # 分类 CRUD
│   ├── account.py             # 账户 CRUD
│   ├── budget.py              # 预算 CRUD
│   └── statistics.py          # 统计查询（月度汇总、分类汇总）
├── ui/
│   ├── __init__.py
│   ├── app.py                 # 主窗口 + 侧边栏导航框架
│   ├── pages/
│   │   ├── overview_page.py   # 总览页
│   │   ├── add_page.py        # 记账页
│   │   ├── bills_page.py      # 账单列表页
│   │   ├── stats_page.py      # 统计页
│   │   ├── budget_page.py     # 预算页
│   │   └── settings_page.py   # 设置页
│   └── widgets/
│       ├── transaction_form.py # 记账表单组件（复用）
│       ├── transaction_list.py # 账单列表组件
│       ├── summary_cards.py    # 收支摘要卡片
│       └── budget_progress.py  # 预算进度条组件
└── utils/
    ├── __init__.py
    └── helpers.py             # 日期/金额格式化工具
```

### 2.3 架构原则

- **分层隔离**：`database/` 负责数据存取，`models/` 封装业务逻辑，`ui/` 专注界面展示
- **页面独立**：每个页面独立文件，便于维护和扩展
- **组件复用**：`widgets/` 中的 UI 组件可在多个页面复用（如记账表单在记账页和编辑对话框中共用）

### 2.4 数据流

```
用户操作 → UI 页面 → models 方法 → database → SQLite
                                    ↓
                            返回结果 → UI 更新
```

## 3. 界面设计

### 3.1 窗口布局

- 窗口大小：约 1000 × 700 像素，固定尺寸
- 单窗口单进程，所有操作在同一个窗口内完成
- **侧边栏**（左侧，宽 70px）：竖排图标按钮，点击切换页面，高亮当前页
- **主内容区**（右侧剩余区域）：根据侧边栏选择展示对应页面内容

### 3.2 页面导航

| 图标 | 页面名称 | 说明 |
|------|----------|------|
| 📊 | 总览 | 默认首页，当月收支摘要，最近账单预览 |
| ➕ | 记账 | 新增账单表单 |
| 📋 | 账单 | 完整账单列表，支持筛选和搜索 |
| 📈 | 统计 | 月度报表和分类图表 |
| 💰 | 预算 | 预算设置和进度追踪 |
| ⚙️ | 设置 | 分类管理、账户管理、数据导出 |

### 3.3 页面交互细节

#### 总览页
- 顶部年月选择器（下拉框），默认当前月
- 三张摘要卡片：总收入（绿色）、总支出（红色）、结余（蓝色，负值红色）
- 最近 5 条账单列表，点击「查看全部」跳转账单页
- 当月预算执行进度简表

#### 记账页
- 类型切换：支出 / 收入 / 转账（三个按钮）
- 金额输入：数字输入框，仅允许正数
- 日期选择：默认当天，支持手动修改
- 分类选择：根据所选类型动态展示对应分类图标网格
- 账户选择：下拉菜单
- 转账时额外显示「目标账户」下拉框
- 备注：可选文字输入框
- 保存按钮：校验 → 入库 → 成功提示 → 清空表单

**表单校验规则：**
- 金额不能为空或 ≤ 0
- 必须选择分类（转账类型除外）
- 必须选择账户
- 转账时源账户和目标账户不能相同

#### 账单页
- 筛选栏：日期范围、类型（全部/支出/收入/转账）、分类（下拉）、备注搜索框
- 按日期降序分组显示，每天一组
- 每条记录：图标 + 分类名 + 备注 + 金额（彩色）+ 账户名
- 点击记录弹出编辑对话框（复用记账表单）
- 编辑对话框内提供「删除」按钮，需二次确认
- 分页：每页 20 条，底部「加载更多」

#### 统计页
- 年度选择器，默认当前年
- 月度收支汇总表（月份 | 收入 | 支出 | 结余）
- 分类占比饼图（支出类 / 收入类分别显示）
- 图表使用 Matplotlib 绘制并嵌入 CTk 窗口

#### 预算页
- 表格形式展示：分类 | 月度预算 | 已支出 | 剩余 | 进度条
- 超支条目进度条变红，显示超支金额
- 点击「编辑预算」弹窗修改金额
- **记账保存时自动检查**：若该分类当月已超支，弹信息提示框

#### 设置页
- 分类管理：分支出/收入两栏展示，支持新增/编辑/删除/重置
- 账户管理：列表展示账户及余额，支持新增/编辑/删除/调余额
- 数据导出：全部导出或按日期范围导出 CSV

## 4. 数据模型

### 4.1 ER 概览

```
categories (1) ──── (N) transactions (N) ──── (1) accounts
                                        │
                                        └── (N) ──── (1) accounts (转账目标)
                    
categories (1) ──── (N) budgets
```

### 4.2 表结构

#### transactions（账单表）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PK | 自动递增 |
| type | TEXT | 'income' / 'expense' / 'transfer' |
| amount | REAL | 金额（正数） |
| category_id | INTEGER FK | 关联 categories.id（转账时为 NULL） |
| account_id | INTEGER FK | 关联 accounts.id |
| to_account_id | INTEGER FK NULL | 目标账户（仅转账类型） |
| note | TEXT | 备注文字 |
| date | TEXT | 日期 YYYY-MM-DD |
| created_at | TEXT | 创建时间戳 |
| updated_at | TEXT | 修改时间戳 |

#### categories（分类表）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PK | 自动递增 |
| name | TEXT | 分类名称 |
| type | TEXT | 'income' / 'expense' |
| icon | TEXT | emoji 图标 |
| sort_order | INTEGER | 排序序号 |

**预置支出分类：** 🍜 餐饮、🚗 交通、🛒 购物、🏠 居住、📱 通讯、🎮 娱乐、🏥 医疗、📚 教育、🎁 人情、✈️ 旅行、❓ 其他

**预置收入分类：** 💼 工资、🏪 兼职、🎯 奖金、📈 理财、🧧 红包、❓ 其他

#### accounts（账户表）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PK | 自动递增 |
| name | TEXT | 账户名称 |
| balance | REAL | 当前余额 |
| icon | TEXT | emoji 图标 |
| sort_order | INTEGER | 排序序号 |

**预置账户：** 💳 现金、🏦 银行卡、📱 支付宝、💚 微信支付

#### budgets（预算表）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PK | 自动递增 |
| category_id | INTEGER FK | 关联 categories.id |
| month | TEXT | 预算月份 YYYY-MM |
| amount | REAL | 预算金额 |

UNIQUE 约束：`(category_id, month)`

### 4.3 数据存储

- 数据库文件路径：`~/.personal_accounting/data.db`
- 首次启动自动创建目录和数据库
- 数据库损坏时自动备份旧文件并重建空库

## 5. 错误处理

| 场景 | 处理方式 |
|------|----------|
| 数据库文件损坏 | 启动时自动检测，备份后重建，弹窗通知用户 |
| 表单输入不合法 | 输入框红色边框 + 底部错误提示文字 |
| 删除有关联数据的分类/账户 | 弹窗提示「该分类下有 N 条账单，请先更换分类」 |
| 金额格式错误 | 输入时限制为数字，保存前二次校验 |

## 6. UI 组件复用策略

- **记账表单组件** (`transaction_form.py`)：在记账页（新增）和账单页（编辑弹窗）中复用
- **摘要卡片组件** (`summary_cards.py`)：在总览页展示当月数据
- **账单列表组件** (`transaction_list.py`)：在总览页（最近 5 条）和账单页（完整列表+分页）中复用
- **预算进度组件** (`budget_progress.py`)：在预算页展示，也在总览页预览

---

## 7. 数据流与状态管理

- 无全局状态管理库，采用简单的「页面刷新」模式：
  - 每次切换到某页面时，从数据库重新读取最新数据
  - 记账保存后自动刷新当前页数据
  - 编辑/删除账单后关闭弹窗并刷新列表
